Randomness you can trust

Computers generate randomness with algorithms called pseudorandom number generators, seeded from unpredictable system events. For everyday uses — raffles, giveaways, classroom picks, game nights — this is more than fair enough. This tool goes a step further and uses your browser's cryptographically secure generator (crypto.getRandomValues), the same source of randomness behind secure web connections, so every outcome is unbiased.

For number generation, each integer in your range has exactly equal probability. Generating 5 unique numbers from 1 to 50 works like drawing lottery balls without putting them back: no repeats, every combination equally likely. Allowing duplicates instead models dice rolls, where each roll is independent and repeats are expected.

The name picker shuffles your list with the Fisher-Yates algorithm — the standard for unbiased shuffling — then takes winners from the top. Because the shuffle touches every position exactly once with a random choice, no name gets preferential treatment, including the first and last entries people often suspect of bias.

A fair draw also needs a clean process: decide the rules before generating (how many winners, whether one person can win twice), paste the full list, and screenshot the result for transparency. For high-stakes draws, consider recording the screen. The math here is fair; documenting the process makes it visibly fair too.

Frequently asked questions

Is this random generator truly random?

It uses your browser's cryptographically secure random generator, which is unbiased and unpredictable — fair for draws, giveaways and games.

Can I pick multiple winners without repeats?

Yes. The picker shuffles the list and takes winners from the top, so the same name cannot win twice unless you run it again.

What is the difference between unique and duplicate numbers?

Unique draws each number once (like lottery balls). Duplicates allow repeats (like dice rolls), where each draw is independent.

Can I use this for a giveaway?

Yes — decide the rules first (number of winners, eligibility), paste all entries, and screenshot the result for transparency.
