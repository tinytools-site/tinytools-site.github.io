How to create a strong password

A strong password has two ingredients: length and unpredictability. Each extra character multiplies the number of guesses an attacker needs, which is why security experts now emphasize length over complex rules. A 16-character random password is enormously harder to crack than an 8-character one, even if the shorter one looks “cleverer”. Mixing uppercase, lowercase, digits and symbols adds further combinations on top.

Randomness matters as much as length. Human-chosen passwords follow predictable patterns — dictionary words, names, dates and keyboard walks like “qwerty” — which cracking tools try first. A generator that picks each character independently from the full set avoids all of these patterns. This tool uses your browser's cryptographically secure random number generator (crypto.getRandomValues), the same class of randomness used for security-sensitive web features.

The strength meter estimates entropy: roughly, the number of possible combinations expressed in bits. Around 60 bits resists casual attacks, 80+ bits is strong against serious ones, and 100+ bits is effectively uncrackable with current technology. A 16-character password drawn from all four character sets lands near 100 bits.

Two practical rules complete the picture. First, never reuse passwords across sites — one breach should not unlock everything you own. A password manager makes unique passwords painless. Second, this generator runs entirely in your browser: generated passwords are never transmitted or stored, but you should still avoid generating passwords on devices you do not trust.

Frequently asked questions

How long should a strong password be?

At least 12 characters; 16 or more is recommended. Length matters more than complexity.

Are the passwords generated here secure?

Yes. Each character is chosen with your browser's cryptographically secure random generator, and nothing is sent over the network.

Should I use symbols in passwords?

They increase the character set and therefore the combinations. Some older systems reject symbols, so the generator lets you exclude them.

Is a password manager better than memorizing?

For most people, yes — it lets you use a unique, long, random password for every site without having to remember any of them.
